BUSINESS ANALYSIS V3 — PROFESSIONAL EDITION

1) Deploy this project to Render using render.yaml.
2) Set OWNER_EMAIL and OWNER_PASSWORD on Render.
3) Open YOUR_API_URL/health and confirm status=ok.
4) Windows: open Desktop_App in Command Prompt.
5) Run: pip install -r requirements.txt
6) Run: python business_analysis_v3.py
7) Login as OWNER.
8) Create a CLIENT in Owner Control Center.
9) Login as the CLIENT and upload CSV/Excel.
10) Use Dashboard, Data Analysis and Reports & Exports.

The backend enforces OWNER/CLIENT roles and client data isolation.
