BUSINESS ANALYSIS V3 PROFESSIONAL — RENDER DEPLOYMENT

1. Upload the CONTENTS of this folder to a GitHub repository. Keep render.yaml at repository root.
2. In Render choose New -> Blueprint and connect the repository.
3. The Blueprint creates: API, PostgreSQL, and Website.
4. When prompted, set OWNER_EMAIL and OWNER_PASSWORD for the initial owner account. Use a strong password.
5. Wait for the API to become Live. Test: https://YOUR-API-URL/health
6. Open the Website URL.
7. On Windows install Desktop_App requirements: pip install -r requirements.txt
8. Run Desktop_Appusiness_analysis_v3.py. Set the API URL to your Render API URL.

IMPORTANT
- This version pins Render Python to 3.13.5 to avoid Python 3.14 dependency builds.
- Do not put OWNER_PASSWORD or JWT_SECRET in GitHub. Render supplies secrets through environment variables.
- Free Render Postgres is for testing/preview and currently expires after 30 days; upgrade for long-term production storage.
